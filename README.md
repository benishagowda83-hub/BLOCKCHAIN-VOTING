# BLOCKCHAIN-VOTING

A menu-driven blockchain-based voting console application written in Python.

## Features

- Add candidates and voters
- Record votes on a proof-of-work blockchain
- Prevent duplicate voter IDs and duplicate votes
- Print all mined blocks and transactions
- Validate block hashes and chain links

## Requirements

- Python 3.9 or newer

## Run

```bash
python voting.py
```

## Menu

1. Add Candidate
2. Add Voter
3. Cast Vote
4. Print Blockchain
5. Validate Chain
6. Exit

Candidate and voter additions, as well as votes, are stored as individual transactions in mined blocks.
